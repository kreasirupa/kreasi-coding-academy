Cara Push Kode ke GitHub & Auto-Deploy Netlify

Pilih cara yang paling nyaman untukmu: menggunakan perintah Terminal/VS Code atau upload langsung lewat browser.

/
1 Tahap Persiapan di GitHub
  1. Simpan kode aplikasi ini sebagai file index.html di dalam satu folder di komputermu (misal: folder kreasi-coding-academy).
  2. Buka github.com/new untuk membuat repository baru.
  3. Isi Repository name dengan kreasi-coding-academy.
  4. Pilih Public atau Private, biarkan opsi Add a README file tidak dicentang, lalu klik Create repository.
Alternatif Tanpa Terminal (Upload via Browser):

Jika tidak ingin memakai Git CLI, di halaman repository GitHub yang baru dibuat klik link biru "uploading an existing file", tarik file index.html ke halaman tersebut, lalu klik tombol hijau Commit changes.

2 Perintah Terminal / VS Code (Push Pertama Kali) 
# 1. Masuk ke folder project di Terminal / VS Code
cd kreasi-coding-academy

# 2. Inisialisasi Git & tambahkan seluruh file
git init
git add .

# 3. Buat commit pertama
git commit -m "Initial commit: Kreasi Coding Academy"

# 4. Pastikan branch utama bernama main
git branch -M main

# 5. Hubungkan ke repository GitHub kamu
git remote add origin https://github.com/username-kamu/kreasi-coding-academy.git

# 6. Push kode ke GitHub
git push -u origin main
Perintah Saat Ada Revisi / Update Materi Berikutnya: 
git add .
git commit -m "Update modul dan kurikulum"
git push
Tahap Akhir • Hubungkan GitHub ke Netlify

Auto-Deploy dari GitHub Repository

  1. Login ke app.netlify.com.
  2. Klik Add new site → Import an existing project → GitHub.
  3. Pilih repository kreasi-coding-academy yang baru kamu push.
  4. Kosongkan Build Command, isi Publish Directory dengan . lalu klik Deploy site.
  5. Selesai! Setiap kali kamu menjalankan git push, website Netlify otomatis ter-update.
Opsi Instan • Tanpa GitHub

Deploy via Netlify Drop (Drag & Drop)

  1. Simpan file ini sebagai index.html di dalam satu folder di komputermu.
  2. Buka app.netlify.com/drop.
  3. Tarik dan lepaskan folder tersebut ke halaman Netlify Drop.
  4. Website langsung online dan siap dihubungkan dengan domain kustom.
